img2threejs Reconstruction Workflow & Testing Guide

1

Stage 1: Image Intake & Technical Probe

Provide a clear reference image (object or character). Run the probe to verify dimensions and aspect ratio:

python forge/stage1_intake/probe_image.py <image.png>
2

Stage 2: Assessment & Strict Sculpt Spec

Score the complexity, detail inventory, and produce the quality-gated JSON spec:

python forge/stage2_spec/new_pre_spec_assessment.py "MyObject" --image <image.png> --out assessment.json
python forge/stage2_spec/new_sculpt_spec.py "MyObject" --image <image.png> --assessment assessment.json --out spec.json
python forge/stage2_spec/validate_sculpt_spec.py spec.json --strict-quality
3

Stage 3: Procedural Three.js Factory Codegen

Generate the TypeScript factory model. No meshes, pure code:

python forge/stage3_build/generate_threejs_factory.py spec.json --out viewer/src/models/myModel.ts
4

Stage 4: Browser Verification & Comparison Sheet

Inspect the model right here in this viewer, capture a screenshot, and package the comparison sheet for gating:

python forge/stage4_review/make_comparison_sheet.py --reference <image.png> --render <render.png> --out review.png
